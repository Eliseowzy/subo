# Subo 标志

反斜杠加一个点。`\` 是每条 LaTeX 命令的开头，点是写完的那一笔。
两笔、不能再少——Subo 要回应的就是「太重」：几个 G 的发行版、一堆插件、离不开网的云端。

`preview.html` 里能看到全部用法和编译动画。

## 文件

| 文件 | 用途 |
|---|---|
| `subo-mark.svg` | 标志，浅底上用 |
| `subo-mark-inverse.svg` | 反白标志，深底上用（页头） |
| `subo-icon.svg` | 深色图标，全出血；应用深色主题首页用这套 |
| `subo-icon-light.svg` | 浅色图标；应用浅色主题首页用这套 |
| `app/public/favicon.svg` | 上面两套合在一个文件里，按系统深浅色切换 |
| `subo-icon-macos.svg` | macOS 图标源文件，按 Apple 网格：1024 画布、824 圆角方块 |
| `subo-icon-1024.png` / `subo.icns` | 由上面的源文件生成，给 Tauri 打包用（macOS、Linux） |

Windows 的图标（`desktop/icons/icon.ico` 和 `Square*Logo.png`）从全出血的 `subo-icon.svg` 生成，不用 macOS 那套：
macOS 网格四周留了约 10% 的透明边，放在 Windows 桌面上会比别的软件小一圈。
`cd desktop && npm run icons` 会把两套都重新生成。

## 几何（120 网格）

- 斜杠：`(36,30) → (62,88)`，线宽 12，圆头。约 66°，与等宽字体里 `\` 的倾角一致。
- 点：圆心 `(82,86)`，半径 8。底边与斜杠收笔齐平，落在同一条基线上。
- 点与斜杠的间距约为半个线宽；改尺寸时整体缩放，不单独调。
- 留白：四周至少留一个点的直径（16）。

## 颜色

| | 浅底 | 深底 |
|---|---|---|
| 斜杠 | `#1f3a33` | `#f7f8f7` |
| 点 | `#2f7d63` | `#6fcf9f` |
| 缺包状态的点 | `#e0a63a` | `#e0a63a` |

点永远是唯一的强调色，斜杠永远是中性色。

## 动态

点就是状态灯：

- 编译中：点从斜杠顶端滑下，落到基线，循环。
- 完成：点停在基线上，就是静态标志。
- 缺包或出错：点变琥珀色。
- 系统开启「减少动态效果」时，编译中改为原地呼吸。

## 别这样用

- 不要给斜杠加颜色，也不要把点换成别的形状。
- 不要加阴影、渐变、描边。
- 不要把点挪到斜杠顶端或左侧——点在右下，是「写完了」。
